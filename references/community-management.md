# Community Management

## Outbound engagement on other creators' posts

1. Identify accounts and posts relevant to the user's niche and audience.
2. Read the actual post context before drafting.
3. Draft a concise, specific, genuinely useful comment.
4. Avoid generic praise, promotional spam, keyword stuffing, and copy-paste templates.
5. Vary wording naturally; never post the same comment repeatedly.
6. Show the exact comment and target URL.
7. Post only with explicit per-comment approval and a supported authorized action tool. If the API does not support the requested public comment operation, do not invent a workaround.

## Replies to comments on the user's own posts

Classify each comment:
- Question
- Positive feedback
- Constructive criticism
- Complaint / support request
- Spam
- Abuse / harassment
- Sensitive or high-risk claim
- Lead / purchase intent

Draft responses in the creator's voice. Escalate refunds, legal threats, safety issues, personal data, medical/financial claims, and serious complaints to a human.

Do not expose private information in public replies. Do not argue with abusive users. For spam, recommend hide/delete/report only if the integration supports it and the user approves.

## Reply quality

- Answer the actual question.
- Be human, concise, and specific.
- Do not manufacture facts or promise outcomes.
- Use a CTA only when contextually useful.
- Match the language of the commenter where possible.

## Messaging

If DM workflows are requested, first check whether an authorized messaging integration is connected and whether the user has the required permissions. Respect messaging windows and platform policy. Do not send unsolicited bulk messages.
