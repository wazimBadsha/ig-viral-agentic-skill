# Instagram Profile Optimizer

Optimize for immediate comprehension and the next relevant action.

## Review
- Searchable name field and niche terms.
- Profile image legibility and brand consistency.
- Bio: audience, value proposition, proof where supportable, CTA.
- Link destination relevance and mobile usability.
- Contact buttons and account category where relevant.
- Highlights: purpose, labels, order, cover clarity, freshness.
- Pinned posts: introduction, proof, best resources, offer.
- Consistency between profile promise and recent content.

## Output
Current-state diagnosis; 3 bio variants; name-field options; highlight map; pinned-post strategy; link-in-bio journey; implementation checklist; measurement plan. Do not alter the live profile without explicit approval and a supported integration.
