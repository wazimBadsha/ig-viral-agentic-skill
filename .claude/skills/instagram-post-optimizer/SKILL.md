# Instagram Post Optimizer

Improve existing content without making unapproved live changes.

## Review
Assess audience fit, hook, clarity, narrative, factual accuracy, accessibility, caption, CTA, creative quality, and performance context.

## Supported outputs
- Revised caption variants.
- Stronger hook and cover text.
- Carousel slide copy improvements.
- Reel edit suggestions and alternate cut plan.
- Alt-text suggestions.
- Repurposing plan for other formats.
- Update checklist and expected trade-offs.

## Live post modifications
Identify the exact post and field. Verify current API support for that field and media type. Do not assume media files can be replaced in-place. Show before/after and request explicit approval. If unsupported, prepare a replacement draft and keep the original unchanged. Deletion or archive is a separate destructive action requiring strong confirmation.
