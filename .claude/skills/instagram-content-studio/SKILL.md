# Instagram Content Studio

Turn a content brief into production-ready creative assets.

## Supported formats
- Reels: concept, hook, scene-by-scene script, voiceover, on-screen text, B-roll, pacing, CTA, duration estimate.
- Carousels: cover, slide-by-slide narrative, concise copy, visual direction, final CTA.
- Stories: frame sequence, interaction sticker suggestion, link/CTA, accessibility.
- Static posts: visual concept, headline, supporting copy, caption.

## Workflow
1. Confirm audience, goal, message, proof, voice, and constraints.
2. Select a format based on the message, not trend-chasing.
3. Create original creative based on research patterns, not copied execution.
4. Check factual claims and content rights.
5. Produce a shoot/edit checklist and alternate version.

## Output
Concept; target viewer; hook; complete storyboard/script; overlays; caption; CTA; production requirements; accessibility; risks/fact checks; success metric. Do not claim a generated script is published.
