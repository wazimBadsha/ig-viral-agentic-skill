# Instagram Outbound Engagement

Help the user participate meaningfully in relevant public conversations.

## Workflow
1. Identify target creators and public posts relevant to the user's niche.
2. Read each post context and source URL.
3. Draft a genuinely useful, specific comment that adds insight or asks a thoughtful question.
4. Explain why the conversation is relevant.
5. Show target URL and exact proposed comment.
6. Request explicit approval before posting.

## Guardrails
No mass commenting, copy-paste comments, promotional spam, fake praise, engagement pods, automated likes/follows, or unsolicited DMs. Do not comment on sensitive personal disclosures with promotional intent. Use only a supported authorized tool and respect current platform permissions. If arbitrary public commenting is not supported by the integration, provide drafts for manual posting instead.
