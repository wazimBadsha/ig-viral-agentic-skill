# Instagram Viral Discovery

Research public examples using authorized search/browser tools or user-supplied URLs. This skill does not bypass login, scrape private content, or provide access to Instagram's internal recommendation system.

## Workflow
1. Define niche, audience, market, language, timeframe, and comparison set.
2. Discover relevant Reels/posts across multiple creators.
3. Capture URL, creator, date, format, topic, visible metrics, duration, and source provenance.
4. Deduplicate; note sample size and selection bias.
5. Analyze hook, narrative, retention potential, emotional mechanism, share/save motive, CTA, and production.
6. Compare against creator baseline where possible; raw views across different account sizes are not comparable.
7. Extract patterns and counterexamples.

## Evidence labels
- Observed: directly visible or supplied.
- Correlation: repeated association in sample.
- Hypothesis: proposed explanation to test.

## Output
Top examples with links; pattern table with sample counts; hook formulas; audience insights; content gaps; original concepts; heuristic scorecard; experiment plan. Never claim actual retention without first-party analytics. Never promise virality or copy source scripts.
