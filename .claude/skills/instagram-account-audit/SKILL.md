# Instagram Account Audit

Produce a prioritized, evidence-aware audit of the account. Request the handle or URL only if not supplied. If profile access is unavailable, ask for screenshots, bio text, recent post URLs, and Insights export; never pretend to have inspected inaccessible content.

## Audit dimensions
1. Positioning: who the account serves, promise, niche clarity, differentiation.
2. Profile: name/search terms, profile image, bio, CTA, link destination, contact options.
3. Content system: pillars, format mix, consistency, recurring series, visual identity.
4. Creative: hooks, clarity, pacing potential, storytelling, accessibility.
5. Audience fit: comments/questions, recurring needs, language, objections.
6. Conversion: path from discovery to follow, click, inquiry, or purchase.
7. Trust: proof, expertise, transparency, claims, and consistency.

## Workflow
- Establish the business/creator goal and target audience.
- Gather only available public or user-authorized evidence.
- Review a representative sample, not only the highest-view post.
- Separate observations, correlations, and hypotheses.
- Score each issue by impact, confidence, effort, and risk.
- Recommend quick wins, medium-term improvements, and experiments.

## Output
Executive diagnosis; strengths; prioritized issues; profile rewrite options; content-pillar recommendations; 7-day action plan; measurement plan. Include evidence URLs or identify user-supplied material. Never guarantee follower growth.
